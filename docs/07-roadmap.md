## 1차 MVP — "유료 분석이 팔리는지 검증"

**목표**: 실제 돈이 오가는 최소한의 흐름을 만든다
**핵심 질문**: "사람들이 카카오톡 분석에 돈을 낼까?"

### 포함 기능
- 모바일 랜딩페이지
- 이메일 회원가입 / 로그인
- 연애 성향 테스트
- 카카오톡 분석 신청 (이미지 + 고민 입력)
- 상품 선택 + 결제 안내 (수동)
- 관리자 대시보드 + AI 초안 생성 + 검수 + 공개
- 리포트 확인 페이지
- 매칭 신청 (단순 신청만)

### 제외 기능
→ CLAUDE.md 섹션 5 참고

### 성공 기준
- 실제 유료 신청 10건 이상
- 리포트 완성 후 재구매 또는 긍정 반응 확인

## 2차 확장 — "자동화 + 편의성 개선"

**목표**: 수동 운영 부담을 줄이고 사용자 경험을 향상시킨다
**핵심 질문**: "더 많은 사람이 쓸 수 있게 만들 수 있을까?"

### 추가할 기능

| 기능 | 설명 |
|------|------|
| 자동 결제 연동 | 토스페이먼츠 또는 포트원 API 연동 |
| 카카오 로그인 | 회원가입 마찰 제거 |
| 리포트 완성 이메일 알림 | 완료 시 사용자에게 자동 이메일 발송 |
| AI 분석 품질 개선 | 프롬프트 고도화, 상품별 분석 깊이 차별화 |
| 재구매 할인 쿠폰 | 재방문 유도 |
| 후기/별점 기능 | 사회적 증거 수집 |
| 관리자 통계 대시보드 | 신청 수, 매출, 처리 속도 등 |
| 이미지 업로드 가이드 | 개인정보 가리는 방법 가이드 영상/이미지 |

## 3차 완성 — "AI 아바타 매칭"

**목표**: 앱의 핵심 차별화 포인트인 AI 아바타 매칭을 구현한다
**핵심 질문**: "AI와 대화하다가 실제 사람과 연결되는 경험이 가능할까?"

### 추가할 기능

| 기능 | 설명 |
|------|------|
| AI 아바타 생성 | 성향 테스트 + 대화 스타일 기반으로 각 사용자의 AI 아바타 생성 |
| AI 아바타 대화 | 상대방의 AI 아바타와 먼저 대화해보는 기능 |
| 호감도 누적 시스템 | AI 아바타와의 대화에서 적합도 점수 축적 |
| 실제 연결 전환 | 호감도 기준 충족 시 실제 사람끼리 연결 제안 |
| 자동 매칭 알고리즘 | 성향, 대화 스타일, 관계 목표 기반 자동 추천 |
| 카카오톡 OCR | 이미지에서 텍스트를 자동으로 추출하여 분석 |
| 커뮤니티 | 연애 고민 게시판 |
| 푸시 알림 | 리포트 완성, 매칭 제안 등 알림 |
| 포인트·추천인 시스템 | 바이럴 성장 구조 |

### 고려사항 (3차 진행 전 검토)
- AI 아바타 기반 데이터는 실제 사용자의 개인정보로 구성됨 → 정보통신망법, 개인정보보호법 검토 필요
- "AI로 상대를 흉내낸다"는 것에 대한 윤리적 가이드라인 수립 필요
- 실제 사람 연결 시 안전장치 (신원 확인, 신고 기능 등) 필요

## 예상 개발 타임라인

| 단계 | 기간 | 주요 완성 목표 |
|------|------|--------------|
| 1차 MVP | 4~6주 | 유료 분석 신청·결제·리포트 흐름 완성 |
| 1차 안정화 | 2~3주 | 버그 수정, 모바일 최적화, 운영 개선 |
| 2차 확장 | 4~8주 | 자동 결제, 카카오 로그인, 알림 |
| 3차 기획 | 2~4주 | AI 아바타 설계, 법적 검토 |
| 3차 개발 | 12주+ | AI 아바타 매칭 시스템 구축 |
