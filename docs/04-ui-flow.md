# 화면 흐름도 및 페이지 목록

> 사용자와 관리자가 각각 어떤 화면을 거치는지 정리합니다.
> 모바일 기준 (375px~430px) 으로 먼저 설계합니다.

---

## 1. 사용자 전체 흐름

```
[랜딩페이지]
    ↓ 회원가입 / 로그인
[로그인 화면]
    ↓
[마이페이지] ←─────────────────────────────────────┐
    ↓ 분석 신청하기 버튼                           │
[연애 성향 테스트] (미완료 시 먼저)               │
    ↓                                              │
[분석 신청 폼]                                    │
    - 관계 상황 선택                               │
    - 고민 내용 입력                               │
    - 이미지 업로드                                │
    - 개인정보 가림 체크 ✅                       │
    ↓                                              │
[상품 선택 + 결제 안내]                           │
    ↓ 결제 완료 후 관리자 확인 대기               │
[분석 대기 화면] ("분석 중입니다")               │
    ↓ 관리자가 리포트 공개 처리 후                │
[리포트 확인 페이지] ──────────────────────────────┘
    ↓ (선택)
[매칭 신청 페이지]
```

---

## 2. 관리자 흐름

```
[관리자 로그인]
    ↓
[신청 목록 대시보드]
    ↓ 신청 항목 클릭
[신청 상세 페이지]
    - 고민 내용 확인
    - 이미지 확인
    - 결제 상태 변경
    - 처리 상태 변경
    ↓ AI 초안 생성 버튼 클릭
[AI 초안 생성 → 에디터에 자동 입력]
    ↓
[운영자 수정 + 저장]
    ↓
[리포트 공개 처리]
    ↓
[매칭 신청자 목록] (별도 메뉴)
```

---

## 3. 페이지별 상세 설명

### P01. 랜딩페이지 `/`
**목적**: 서비스 소개 + 회원가입/로그인 유도

**포함 내용**
- 헤드라인 카피 (예: "카톡 한 줄도 분석해드립니다")
- 서비스 흐름 3단계 요약
- 상품 3종 소개 + 가격
- 후기 또는 신뢰 요소 (나중에 추가)
- 회원가입 / 로그인 버튼

**디자인 방향**
- 따뜻하고 공감 가는 톤
- 연한 핑크·보라 계열 (또는 결정 후 수정)
- 스크롤 없이 핵심이 보이도록

---

### P02. 회원가입 `/auth/signup`
- 이메일, 비밀번호 입력
- 약관 동의 체크박스
- 이미 계정이 있으면 로그인으로 이동

### P03. 로그인 `/auth/login`
- 이메일, 비밀번호 입력
- 비밀번호 찾기 링크
- 회원가입으로 이동 링크

---

### P04. 마이페이지 `/mypage`
**목적**: 내 신청 내역 전체 확인

**포함 내용**
- 내 이메일 / 닉네임
- 분석 신청 내역 목록
  - 신청일 / 상품명 / 결제 상태 / 처리 상태
  - 완료된 건: "리포트 보기" 버튼
  - 진행 중인 건: "분석 중" 상태 표시
- 새 신청하기 버튼
- 매칭 신청 여부

---

### P05. 연애 성향 테스트 `/test`
**목적**: 사용자 성향 파악 + 추후 매칭에 활용

**포함 내용**
- 질문 10~15개 (객관식 + 선택지)
- 진행률 표시 바 (예: 3/12)
- "이전" / "다음" 버튼
- 결과 화면: 성향 유형명 + 간단 설명

**질문 예시 카테고리**
- 대화 스타일 (자주 연락 vs 필요할 때)
- 연애 속도 (천천히 vs 빠르게)
- 갈등 해결 방식
- 연락 빈도 선호
- 데이트 스타일

---

### P06. 분석 신청 폼 `/apply`
**목적**: 카카오톡 분석 신청 정보 입력

**포함 내용**
- Step 1: 관계 상황 선택 (썸 / 소개팅 / 연애 / 재회)
- Step 2: 고민 내용 입력 텍스트 영역 (글자수 카운트 표시)
- Step 3: 이미지 업로드 (최대 5장)
  - 업로드 전 안내 문구: "상대방 이름, 얼굴, 전화번호, 카카오톡 ID를 가려주세요"
  - 업로드된 이미지 미리보기
- Step 4: 개인정보 가림 확인 체크박스
  - 체크하지 않으면 "다음" 버튼 비활성화
- 전체를 한 페이지 또는 스텝별로 구성

---

### P07. 상품 선택 + 결제 안내 `/apply/[id]/payment`
**포함 내용**
- 상품 3종 카드 (가격 + 포함 내용)
- 선택한 상품 강조 표시
- 결제 안내 영역
  - 계좌번호 표시
  - 또는 외부 결제링크 버튼
- "입금 확인 후 분석이 시작됩니다" 안내
- 문의 연락처

---

### P08. 리포트 확인 `/report/[id]`
**포함 내용**
- 공개 상태가 아니면: "현재 분석 준비 중입니다. 완료 시 이메일로 안내드립니다."
- 공개 상태면:
  - 현재 상황 요약
  - 호감 가능성 (가능성 표현 중심)
  - 긍정 신호 목록
  - 부정 신호 목록
  - 지금 하면 안 되는 행동
  - 추천 답장 (카드 형태)
  - 3일 코칭 / 7일 코칭 (상품 등급에 따라)
  - 방향성 제안
- "매칭 신청하기" 버튼 (하단)

---

### P09. 매칭 신청 `/match`
**포함 내용**
- 매칭 서비스 간단 설명
- 성향 테스트 완료 여부 확인
  - 미완료 시: "성향 테스트 먼저 해주세요" 안내 + 이동 버튼
- 매칭 신청 버튼
- "검토 후 연락드립니다" 완료 메시지

---

### A01. 관리자 신청 목록 `/admin`
**포함 내용**
- 전체 신청 목록 테이블
- 필터: 결제 상태 / 처리 상태
- 각 행: 신청일 / 이메일 / 상품 / 결제상태 / 처리상태 / 상세 버튼

### A02. 관리자 신청 상세 `/admin/requests/[id]`
**포함 내용**
- 신청자 정보 + 고민 내용
- 이미지 뷰어 (private URL)
- 결제 상태 변경 드롭다운
- 처리 상태 변경 드롭다운
- AI 초안 생성 버튼
- 리포트 에디터 (AI 초안 자동 입력 → 수정 가능)
- 저장 / 공개 처리 버튼

### A03. 매칭 신청자 목록 `/admin/matches`
**포함 내용**
- 매칭 신청 목록
- 각 신청자의 성향 테스트 결과 확인
- 상태 변경 (pending / reviewing / matched / closed)

## 4. 공통 UI 요소

- 상단 네비게이션 바 (로고 + 마이페이지 + 로그아웃)
- 하단 탭 바 (홈 / 신청 / 마이페이지) — 모바일 앱처럼
- 로딩 스피너 (API 호출 중)
- 토스트 알림 (성공 / 오류 메시지)
- 모달 팝업 (확인/취소 선택)
