# 수익화 구조 및 상품 정의서

> 1차 MVP의 수익 모델과 운영 흐름을 정의합니다.

## 1. 상품 구성

### 상품 1: 썸톡 간단 분석
| 항목 | 내용 |
|------|------|
| 가격 | **9,900원** |
| 포함 분석 | 현재 상황 요약, 호감 가능성, 긍정 신호, 부정 신호, 추천 답장 3개 |
| 타겟 고객 | 빠르게 현재 상황만 파악하고 싶은 사람 |
| 처리 소요 시간 (목표) | 결제 확인 후 24시간 이내 |

### 상품 2: 썸톡 심층 분석
| 항목 | 내용 |
|------|------|
| 가격 | **29,000원** |
| 포함 분석 | 상황 요약, 관계 단계 분석, 대화 흐름 분석, 감정 신호, 위험 신호, 지금 하면 안 되는 행동, 3일 전략, 추천 답장, 방향성 제안 |
| 타겟 고객 | 깊이 있는 분석과 행동 지침이 필요한 사람 |
| 처리 소요 시간 (목표) | 결제 확인 후 48시간 이내 |

### 상품 3: 7일 대화 코칭
| 항목 | 내용 |
|------|------|
| 가격 | **99,000원** |
| 포함 분석 | 심층 분석 전체 + 7일간 답장 방향 코칭, 상황별 메시지 피드백 |
| 타겟 고객 | 장기적으로 관계를 이어가거나 재회를 원하는 사람 |
| 처리 소요 시간 (목표) | 결제 확인 후 72시간 이내 / 이후 7일 동안 추가 피드백 |
| 운영 방식 | 초기에는 관리자가 직접 이메일 또는 문자로 피드백 제공 |

## 2. 결제 방식 (1차 MVP)

**자동 결제 API를 사용하지 않고 수동으로 처리합니다.**

### 결제 흐름
```
1. 사용자가 상품 선택
2. 결제 안내 페이지에서 계좌번호 확인 (또는 외부 결제링크)
3. 사용자가 직접 입금 또는 결제링크 결제
4. 관리자가 입금 확인
5. 관리자가 결제 상태를 "결제완료"로 변경
6. 분석 작업 시작
```

### 결제 수단 옵션
- **계좌이체**: 관리자 계좌번호 직접 표시
- **외부 결제링크**: 토스, 카카오페이 등 간편 결제링크 생성 후 URL 공유
  - 예: 토스 개인 링크, 카카오페이 요청 링크

## 3. 운영 수수료 계산

| 상품 | 판매가 | 예상 원가 (AI API) | 예상 순수익 |
|------|--------|-------------------|------------|
| 간단 분석 | 9,900원 | 약 100~300원 | 약 9,600원 |
| 심층 분석 | 29,000원 | 약 300~700원 | 약 28,300원 |
| 7일 코칭 | 99,000원 | 약 500~1,000원 + 운영 시간 | 가변 |

> AI API 비용은 토큰 수에 따라 달라지며, 위 수치는 예상값입니다.

## 4. MVP 검증 지표 (목표)

| 지표 | 목표 |
|------|------|
| 첫 달 유료 신청 | 10건 이상 |
| 재구매율 | 20% 이상 |
| 분석 완료 평균 시간 | 48시간 이내 |
| 환불 요청 비율 | 5% 이하 |

---

## 5. 장기 수익화 방향 (2차·3차)

| 기능 | 예상 수익 모델 |
|------|--------------|
| AI 아바타 매칭 | 매칭 성사 시 수수료 또는 프리미엄 구독 |
| 월정액 코칭 구독 | 월 X만원에 무제한 분석 |
| 기업 B2B | 결혼정보회사 데이터 파트너십 |
| 자동 결제 연동 | 토스페이먼츠 API 연동으로 수동 확인 제거 |

---

## 6. 환불 정책 (초안)

- **분석 시작 전**: 전액 환불
- **분석 진행 중**: 50% 환불
- **리포트 공개 후**: 환불 불가
- **부적절한 콘텐츠 포함 신청**: 환불 없이 거부 처리

> 이 정책은 서비스 약관에 명시해야 합니다.
