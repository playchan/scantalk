데이팅 앱은 왜 피로한가

매칭 이후의 모든 노동이 사용자 몫으로 남아 있다

첫 대화

시작의 부담

매칭이 되어도 "뭐라고 말을 걸지"부터 막힌다. 대화 시작 자체가 노동이 된 시장.

반복되는 상처

노력↑ 성사↓

기존 데이팅 앱은 "사람이 직접 뛰는" 구조라서 생기는 마찰을 해결하지 못했다.

내 AI봇이 나 대신 뛴다

첫 대화의 부담도, 거절의 상처도 봇이 대신 겪는다

  • 검사 한 번 = 나의 AI봇 생성.
    무료 검사 응답이 그대로 봇의 성격·말투·연애 성향이 된다.
  • 봇이 자동으로 대화한다.
    궁합이 맞을 것 같은 상대와 알아서 대화 — 게임의 '자동사냥'처럼.
  • 대화 내용은 절대 비공개.
    나는 상대별 호감도 %만 본다. "내 봇이 뭐라고 했을까"라는 궁금증이 곧 재미.
  • 거절 경험이 구조적으로 없다.
    양쪽 모두 수락해야만 실제 대화가 열린다. 한쪽만 수락하면 상대는 모른다.

무료 콘텐츠에서 결제까지, 5단계 퍼널

획득 → 전환 → 활성화 → 매칭 → 수익화가 한 제품 안에서 끝난다

1 · 유입바이럴 무료 검사"내가 결혼할 확률은?" — MBTI처럼 공유되며 퍼지는 검사
›
2 · 전환AI봇 생성검사 완료 = 나의 봇 탄생. 결과 직전 간편 가입
›
3 · 활성화익명 봇 대화봇이 궁합 상대와 자동 대화. 내용 비공개, 호감도 %만
›
4 · 매칭양측 수락임계치 도달 → 둘 다 수락 시에만 실제 채팅 오픈
›
5 · 수익화매칭 오픈권 결제+ 구독 · 부스터 · 카톡 분석 크로스셀

왜 이 퍼널이 강한가

획득 비용이 콘텐츠 제작비뿐이다. 검사 결과 공유가 곧 광고이고, 검사 데이터가 곧 제품(봇)이 된다. CAC를 콘텐츠가 대체하는 구조.

결제 타이밍

"진짜 사람과 이어지는 순간"에만 지갑을 연다. 첫 매칭 무료 → 두 번째부터 과금. 가치를 체감한 뒤에 결제가 온다.

수익원 4개 — 가치를 체감한 순간에 과금

핵심은 매칭 오픈권, 기존 카톡 분석 상품이 두 번째 엔진

수익원내용가격시점
매칭 오픈권 핵심호감도 임계치 도달 후 실제 대화방 오픈. 첫 매칭 무료 → 2번째부터 과금건당 4,900~9,900원라운드 4
프리미엄 구독봇 동시 대화 슬롯 확대, 호감도 상세 그래프, 우선 매칭월 9,900원라운드 4 이후
부스터내 봇이 더 많은 상대에게 먼저 말 걸기건당 소액라운드 4 이후
카톡 분석 크로스셀매칭 후 실제 대화 시작 유저에게 기존 분석 상품 노출 — "이 대화, 잘 되고 있을까요?"9,900 / 29,000 / 99,000원즉시 (기제품)

원가 구조

주 원가는 AI API — 기존 분석 상품 기준 건당 100~1,000원 수준으로 마진율이 높다. 봇 대화는 턴 수·상대 수 상한과 일일 비용 캡으로 통제.

기존 제품이 곧 두 번째 수익원

카톡 분석 MVP는 개발 완료 상태. v2 매칭이 분석 상품의 신규 고객 파이프라인이 되는 이중 구조.

Risk & MitigationSCANTALK

리스크는 알고 있고, 대응은 설계되어 있다

각 리스크의 대응이 이미 라운드 계획 안에 배치되어 있다

콜드 스타트

초기 유저가 적으면 봇이 대화할 상대가 없다.

→ R1 사전신청자를 모아 같은 날 동시 오픈. 초기 밀도를 인위적으로 확보.

AI 비용 폭주

봇↔봇 대화는 유저가 없어도 API가 돈다.

→ 동시 상대 3명·턴 수·배치 주기 상한 + 유저당 일일 비용 캡 + 대시보드 실시간 모니터링.

법적 · 윤리

내 데이터로 봇이 나 몰래 대화하는 구조.

→ 가입 시 명시 동의 + 봇 발언 면책 고지 + 개인정보 발화 금지 가드레일 + R4 전 성인 인증 + 탈퇴 시 완전 삭제.

기대 관리

"호감도 90%인데 만나보니 별로"

→ 호감도는 '대화 궁합' 지표임을 UX 전반에 명시. 과잉 약속 문구 금지 원칙.
