# 보안·개인정보 체크리스트

> 이 앱은 카카오톡 대화, 연애 고민, 개인 성향 등 민감한 데이터를 다룹니다.
> 아래 항목은 개발 단계별로 반드시 확인해야 하는 필수 체크리스트입니다.

---

## 1. API 키 보안

| 체크 | 항목 |
|------|------|
| ☐ | `.env.local` 파일이 `.gitignore`에 포함되어 있는가 |
| ☐ | GitHub에 `.env.local`이 올라가지 않았는가 |
| ☐ | `SUPABASE_SERVICE_ROLE_KEY`가 클라이언트 코드에 없는가 |
| ☐ | `ANTHROPIC_API_KEY`가 클라이언트 코드에 없는가 |
| ☐ | `NEXT_PUBLIC_` 접두사 변수만 클라이언트에서 사용하는가 |
| ☐ | Vercel 환경 변수에 Production 설정이 완료되었는가 |

---

## 2. Supabase 보안

| 체크 | 항목 |
|------|------|
| ☐ | 모든 테이블에 RLS(Row Level Security)가 활성화되어 있는가 |
| ☐ | 사용자는 본인 데이터만 조회 가능한 RLS 정책이 설정되어 있는가 |
| ☐ | 관리자 권한 체크 RLS 정책이 설정되어 있는가 |
| ☐ | 이미지 저장 버킷이 private으로 설정되어 있는가 |
| ☐ | public bucket이 사용되지 않는가 |
| ☐ | Storage 접근 시 signed URL을 사용하는가 |
| ☐ | signed URL 유효 시간이 1시간 이내로 설정되어 있는가 |

---

## 3. 사용자 데이터 보호

| 체크 | 항목 |
|------|------|
| ☐ | 이미지 업로드 전 개인정보 가림 안내 문구가 표시되는가 |
| ☐ | 개인정보 가림 확인 체크박스가 없으면 신청이 불가능한가 |
| ☐ | 체크박스 미선택 시 신청 버튼이 비활성화(disabled)되는가 |
| ☐ | 사용자가 타인의 리포트 URL로 직접 접근할 수 없는가 |
| ☐ | 미공개 리포트(`is_published = false`)가 사용자에게 보이지 않는가 |
| ☐ | 결제 확인 전에 리포트가 공개되지 않는가 |

---

## 4. 관리자 권한 보안

| 체크 | 항목 |
|------|------|
| ☐ | 관리자 페이지에 권한 체크가 모든 페이지에 적용되어 있는가 |
| ☐ | 관리자 API Route에서 서버 사이드로 권한을 확인하는가 |
| ☐ | 관리자 계정 이메일/비밀번호가 추측하기 어려운가 |
| ☐ | 일반 사용자가 `/admin` 경로에 접근하면 차단되는가 |

---

## 5. AI 분석 콘텐츠 안전

| 체크 | 항목 |
|------|------|
| ☐ | AI 분석 결과에 "상대는 당신을 좋아합니다" 같은 확정 표현이 없는가 |
| ☐ | 가능성·신호 중심 표현을 사용하는 프롬프트가 설정되어 있는가 |
| ☐ | 스토킹, 집착, 조작, 불법 추적 관련 요청을 거부하는가 |
| ☐ | 미성년자 관련 상황으로 판단되면 경고 문구가 삽입되는가 |
| ☐ | 부적절한 요청이 들어오면 관리자 알림이 가는가 |

## 6. 일반 웹 보안

| 체크 | 항목 |
|------|------|
| ☐ | SQL Injection 방지 (Supabase SDK 사용 — 직접 쿼리 사용 금지) |
| ☐ | XSS 방지 (사용자 입력값을 HTML에 직접 삽입하지 않는가) |
| ☐ | 파일 업로드 시 이미지 파일 형식만 허용하는가 (jpg, png, heic) |
| ☐ | 파일 크기 제한이 설정되어 있는가 (예: 장당 10MB 이하) |
| ☐ | HTTPS로만 접근 가능한가 (Vercel 기본 제공) |

## 7. 개인정보처리방침 (서비스 오픈 전 필수)

| 체크 | 항목 |
|------|------|
| ☐ | 개인정보처리방침 페이지가 있는가 |

---

## 8. 운영 중 주기적으로 확인할 사항

- 사용 중인 API 키가 외부에 유출되지 않았는지 확인
- Supabase의 RLS 정책이 의도대로 작동하는지 주기적으로 테스트
- 관리자 계정 비밀번호 주기적 변경 (3개월에 한 번 권장)
- 업로드된 이미지 중 개인정보가 가려지지 않은 이미지 발견 시 즉시 삭제 처리

## 9. 사용자 안내 문구 (UI에 반드시 포함)

### 이미지 업로드 전 안내
```
카카오톡 캡처 이미지 업로드 전 반드시 아래 내용을 가려주세요:
✅ 상대방 이름 (카카오톡 프로필 이름)
✅ 상대방 프로필 사진 (얼굴)
✅ 전화번호
✅ 카카오톡 ID
✅ 기타 제3자의 개인정보

가리지 않은 이미지가 업로드될 경우 분석이 거부될 수 있습니다.
```
